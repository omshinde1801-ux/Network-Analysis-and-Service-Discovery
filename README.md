
# Network Analysis & Service Discovery

## Project Overview
A hands-on Cybersecurity Lab Project performed using Kali Linux, Wireshark and Nmap.

The objective is to analyze network traffic, inspect protocols, identify open ports and discover services running on an authorized lab target.

## Tools & Technologies
- Kali Linux
- Wireshark
- Nmap
- Metasploitable 2

## Practical Tasks
1. Network Configuration
2. DNS Traffic Analysis
3. TCP SYN Packet Inspection
4. TLS Traffic Observation
5. Nmap TCP Service Discovery
6. Security Findings and Recommendations

## Key Learnings
- Understanding DNS queries and responses.
- Analyzing TCP packet flags.
- Observing TLS handshake metadata.
- Identifying open ports and services.
- Understanding network security risks.
